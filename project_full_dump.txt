# Secure Notes Application

An AES-256-GCM encrypted personal notes web application built as a cybersecurity academic project. Users can register, log in, and manage private notes. All note content is encrypted in the database using AES-256-GCM. Access is strictly controlled — a user can never read, modify, or delete another user's notes.

---

## Problem Statement

Storing personal notes in plain text on a server is risky. If the database is compromised, all note content is immediately readable. Additionally, without proper access control, one user could read or modify another user's data simply by guessing or manipulating IDs.

This project demonstrates how to build a note-taking application that:
- Encrypts note content before storing it in the database
- Hashes passwords so they are never stored in readable form
- Uses server-side session management so authentication cannot be faked
- Enforces ownership checks on the server so the frontend cannot bypass access control

---

## Objectives

- Implement secure user registration and login
- Store passwords as bcrypt hashes (never plaintext)
- Encrypt note content with AES-256-GCM before saving to the database
- Enforce that users can only access their own notes
- Protect against common web vulnerabilities (XSS, SQL injection, CSRF)
- Validate all input before processing
- Handle errors safely without exposing internals

---

- User registration with email and password
- Secure login and logout
- Session-based authentication with HTTP-only cookies

## Database Schema

### User table
```
id           INTEGER  PRIMARY KEY AUTOINCREMENT
email        TEXT     UNIQUE NOT NULL
passwordHash TEXT     NOT NULL          -- bcrypt hash, cost 12
createdAt    DATETIME DEFAULT now()
updatedAt    DATETIME
```

### Note table
```
id        INTEGER  PRIMARY KEY AUTOINCREMENT
userId    INTEGER  NOT NULL REFERENCES User(id) ON DELETE CASCADE
title     TEXT     NOT NULL
content   TEXT     NOT NULL  -- AES-256-GCM encrypted hex string
iv        TEXT     NOT NULL  -- 128-bit initialization vector (hex)
authTag   TEXT     NOT NULL  -- GCM authentication tag (hex)
createdAt DATETIME DEFAULT now()
updatedAt DATETIME
```

Every note has a `userId` foreign key. The `content` field is never stored in plain text — it is encrypted using AES-256-GCM before insert, and decrypted on read.

## Authentication Workflow

### Registration
```
1. User submits email + password
2. Backend validates email format, password length and complexity
3. Check if email already exists → reject if duplicate
4. Hash password with bcrypt (cost factor 12)
5. Store { email, passwordHash } in database
6. Return success (never return the hash)
```

### Login
```
1. User submits email + password
2. Backend validates input
3. Look up user by email
4. Compare submitted password with stored hash using bcrypt.compare()
5. If match → regenerate session (prevents session fixation)
6. Store userId in session
7. Set HTTP-only, SameSite=Strict cookie
8. Return user info (no hash, no session secret)
```

---

## Authorization Workflow

Every protected route passes through `requireAuth` middleware:

```
Request arrives
       │
       ▼
requireAuth middleware
       │
       ├── session.userId missing? → 401 Unauthorized
       │
       └── session.userId present → attach to req.userId → continue
                                              │
                                              ▼
                                    Notes controller
                                              │
                                    Find note in database
                                              │
                                    note.userId === req.userId?
                                              │
                                    NO → 403 Forbidden
                                    YES → proceed
```

The `userId` is **always taken from the session**. The client cannot pass a `userId` in the request body to access another user's notes — it is completely ignored.

---

## Security Mechanisms

### 1. AES-256-GCM Encryption
- Every note's content is encrypted before database storage
- Each note gets a unique random 128-bit IV
- GCM mode provides both confidentiality and integrity (authenticated encryption)
- The `authTag` prevents tampering — decryption fails if content was modified
- Encryption key stored in `.env`, never in source code

### 2. Password Hashing (bcrypt, cost 12)
- Passwords are hashed on registration

const crypto = require('crypto');

// Key must be 32 bytes (256-bit) for AES-256
function getKey() {
  const keyHex = process.env.ENCRYPTION_KEY;
  if (!keyHex || keyHex.length !== 64) {
    throw new Error('ENCRYPTION_KEY must be set and be 64 hex characters (32 bytes)');
  }
  return Buffer.from(keyHex, 'hex');
}

// Encrypt text using AES-256-GCM
// Returns: { encryptedContent, iv, authTag }
function encrypt(text) {
  const key = getKey();
  const iv = crypto.randomBytes(16); // 128-bit IV
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);

  let encrypted = cipher.update(text, 'utf8', 'hex');
  encrypted += cipher.final('hex');

  const authTag = cipher.getAuthTag();

  return {
    encryptedContent: encrypted,
    iv: iv.toString('hex'),
    authTag: authTag.toString('hex'),
  };
}

// Decrypt text using AES-256-GCM
// Returns: decrypted string
function decrypt(encryptedContent, ivHex, authTagHex) {
  const key = getKey();
  const iv = Buffer.from(ivHex, 'hex');
  const authTag = Buffer.from(authTagHex, 'hex');

  const decipher = crypto.createDecipheriv('aes-256-gcm', key, iv);
  decipher.setAuthTag(authTag);

  let decrypted = decipher.update(encryptedContent, 'hex', 'utf8');
  decrypted += decipher.final('utf8');

  return decrypted;
}

module.exports = { encrypt, decrypt };

// Middleware to check if user is authenticated
// Attaches req.userId if valid session exists

function requireAuth(req, res, next) {
  if (!req.session || !req.session.userId) {
    return res.status(401).json({ error: 'Unauthorized. Please log in.' });
  }
  req.userId = req.session.userId;
  next();
}

const logger = require('../utils/logger');

// Central error handler - never exposes stack traces or internals to the client
function errorHandler(err, req, res, next) {
  // Log the real error server-side
  logger.error(`${err.message} | Route: ${req.method} ${req.path} | Stack: ${err.stack}`);

  // Prisma unique constraint violation (duplicate email)
  if (err.code === 'P2002') {
    return res.status(409).json({ error: 'An account with that email already exists.' });
  }

  // Prisma record not found
  if (err.code === 'P2025') {
    return res.status(404).json({ error: 'Resource not found.' });
  }

  // Generic fallback - do not expose internals
  const statusCode = err.status || 500;
  const message = statusCode === 500 ? 'Internal server error.' : err.message;

  res.status(statusCode).json({ error: message });
}

module.exports = { errorHandler };

const bcrypt = require('bcryptjs');
const { validationResult } = require('express-validator');
const prisma = require('../database/prismaClient');
const logger = require('../utils/logger');

// POST /api/auth/register
async function register(req, res, next) {
  try {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }

    const { email, password } = req.body;

    // Check if user already exists
    const existing = await prisma.user.findUnique({ where: { email } });
    if (existing) {
      return res.status(409).json({ error: 'An account with that email already exists.' });
    }

    // Hash password - cost factor 12
    const passwordHash = await bcrypt.hash(password, 12);

    // Create user - never store plaintext password
    const user = await prisma.user.create({
      data: { email, passwordHash },
      select: { id: true, email: true, createdAt: true }, // never return hash
    });

    logger.info(`New user registered: ${user.email}`);

    res.status(201).json({ message: 'Account created successfully.', user });
  } catch (err) {
    next(err);
  }
}

// POST /api/auth/login
async function login(req, res, next) {
  try {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }

    const { email, password } = req.body;

    // Find user
    const user = await prisma.user.findUnique({ where: { email } });

    // Use constant-time comparison via bcrypt - same response for wrong email or wrong password
    // to avoid account enumeration
    if (!user) {
      return res.status(401).json({ error: 'Invalid email or password.' });
    }

    const passwordMatch = await bcrypt.compare(password, user.passwordHash);
    if (!passwordMatch) {
      logger.info(`Failed login attempt for: ${email}`);
      return res.status(401).json({ error: 'Invalid email or password.' });
    }

    // Regenerate session to prevent session fixation
    req.session.regenerate((err) => {
      if (err) return next(err);

      req.session.userId = user.id;
      req.session.email = user.email;

      logger.info(`User logged in: ${user.email}`);

      res.json({
        message: 'Logged in successfully.',
        user: { id: user.id, email: user.email },
      });
    });
  } catch (err) {
    next(err);
  }
}

// POST /api/auth/logout
function logout(req, res, next) {
  req.session.destroy((err) => {
    if (err) return next(err);
    res.clearCookie('sid');
    res.json({ message: 'Logged out successfully.' });
  });
}

// GET /api/auth/me
async function me(req, res, next) {
  try {
    const user = await prisma.user.findUnique({
      where: { id: req.userId },
      select: { id: true, email: true, createdAt: true },
    });

    if (!user) {
      return res.status(404).json({ error: 'User not found.' });
    }

    res.json({ user });
  } catch (err) {
    next(err);
  }
}

module.exports = { register, login, logout, me };

const { validationResult } = require('express-validator');
const prisma = require('../database/prismaClient');
const { encrypt, decrypt } = require('../services/cryptoService');
const logger = require('../utils/logger');

// GET /api/notes - get all notes for the logged-in user
async function getNotes(req, res, next) {
  try {
    const notes = await prisma.note.findMany({
      where: { userId: req.userId },
      orderBy: { updatedAt: 'desc' },
      select: { id: true, title: true, createdAt: true, updatedAt: true },
      // content is not returned in list view - only titles
    });

    res.json({ notes });
  } catch (err) {
    next(err);
  }
}

// GET /api/notes/:id - get a single note (must belong to authenticated user)
async function getNoteById(req, res, next) {
  try {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }

    const noteId = parseInt(req.params.id);

    const note = await prisma.note.findUnique({ where: { id: noteId } });

    if (!note) {
      return res.status(404).json({ error: 'Note not found.' });
    }

    // Ownership check - MUST be server-side
    if (note.userId !== req.userId) {
      logger.info(`Unauthorized note access attempt: user ${req.userId} tried to access note ${noteId} owned by user ${note.userId}`);
      return res.status(403).json({ error: 'Access denied.' });
    }

    // Decrypt the content before sending
    const content = decrypt(note.content, note.iv, note.authTag);

    res.json({
      note: {
        id: note.id,
        title: note.title,
        content,
        createdAt: note.createdAt,
        updatedAt: note.updatedAt,
      },
    });
  } catch (err) {
    next(err);
  }
}

// POST /api/notes - create a new note
async function createNote(req, res, next) {
  try {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }

    const { title, content } = req.body;

    // userId always comes from session, never from request body
    const userId = req.userId;

    // Encrypt note content with AES-256-GCM
    const { encryptedContent, iv, authTag } = encrypt(content);

    const note = await prisma.note.create({
      data: {
        title,
        content: encryptedContent,
        iv,
        authTag,
        userId,
      },
      select: { id: true, title: true, createdAt: true },
    });

    logger.info(`Note created: id=${note.id} user=${userId}`);

    res.status(201).json({ message: 'Note created.', note });
  } catch (err) {
    next(err);
  }
}

// PUT /api/notes/:id - update a note
async function updateNote(req, res, next) {
  try {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }

    const noteId = parseInt(req.params.id);
    const { title, content } = req.body;

    // Find note first
    const existing = await prisma.note.findUnique({ where: { id: noteId } });

    if (!existing) {
      return res.status(404).json({ error: 'Note not found.' });
    }

    // Ownership check - server-side
    if (existing.userId !== req.userId) {
      logger.info(`Unauthorized update attempt: user ${req.userId} tried to update note ${noteId}`);
      return res.status(403).json({ error: 'Access denied.' });
    }

    // Encrypt new content
    const { encryptedContent, iv, authTag } = encrypt(content);

    const updated = await prisma.note.update({
      where: { id: noteId },
      data: { title, content: encryptedContent, iv, authTag },
      select: { id: true, title: true, updatedAt: true },
    });

    logger.info(`Note updated: id=${noteId} user=${req.userId}`);

    res.json({ message: 'Note updated.', note: updated });
  } catch (err) {
    next(err);
  }
}

// DELETE /api/notes/:id - delete a note
async function deleteNote(req, res, next) {
  try {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }

    const noteId = parseInt(req.params.id);

    // Find note first
    const existing = await prisma.note.findUnique({ where: { id: noteId } });

    if (!existing) {
      return res.status(404).json({ error: 'Note not found.' });
    }

    // Ownership check - server-side
    if (existing.userId !== req.userId) {
      logger.info(`Unauthorized delete attempt: user ${req.userId} tried to delete note ${noteId}`);
      return res.status(403).json({ error: 'Access denied.' });
    }

    await prisma.note.delete({ where: { id: noteId } });

    logger.info(`Note deleted: id=${noteId} user=${req.userId}`);

    res.json({ message: 'Note deleted.' });
  } catch (err) {
    next(err);
  }
}

// API service - all requests to backend go through here
// Using /api prefix which Vite proxies to http://localhost:3001

const BASE = '/api';

async function request(method, path, body) {
  const options = {
    method,
    headers: { 'Content-Type': 'application/json' },
    credentials: 'include', // send session cookie with every request
  };

  if (body) {
    options.body = JSON.stringify(body);
  }

  const res = await fetch(`${BASE}${path}`, options);
  const data = await res.json();

  if (!res.ok) {
    // Throw error with message from server
    const message = data.error || data.errors?.[0]?.msg || 'Something went wrong.';
    throw new Error(message);
  }

  return data;
}

import { createContext, useContext, useState, useEffect } from 'react';
import { getMe, logout as apiLogout } from '../services/api';

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  // Check if user is already logged in on app load
  useEffect(() => {
    getMe()
      .then((data) => setUser(data.user))
      .catch(() => setUser(null))
      .finally(() => setLoading(false));
  }, []);

  function login(userData) {
    setUser(userData);
  }

  async function logout() {
    await apiLogout();
    setUser(null);
  }

  return (
    <AuthContext.Provider value={{ user, loading, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  return useContext(AuthContext);
}

import { useState, useEffect } from 'react';
import { Link } from 'react-router-dom';
import { getNotes, deleteNote } from '../services/api';

function DashboardPage() {
  const [notes, setNotes] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState('');

  useEffect(() => {
    loadNotes();
  }, []);

  async function loadNotes() {
    try {
      const data = await getNotes();
      setNotes(data.notes);
    } catch (err) {
      setError('Failed to load notes.');
    } finally {
      setLoading(false);
    }
  }

  async function handleDelete(id) {
    if (!window.confirm('Delete this note?')) return;

    try {
      await deleteNote(id);
      setNotes((prev) => prev.filter((n) => n.id !== id));
    } catch (err) {
      setError(err.message);
    }
  }

  function formatDate(dateStr) {
    return new Date(dateStr).toLocaleDateString('en-IN', {
      day: '2-digit',
      month: 'short',
      year: 'numeric',
    });
  }

  if (loading) return <div className="loading">Loading notes...</div>;

  return (
    <div className="container">
      <div className="notes-header">
        <h2>My Notes</h2>
        <Link to="/notes/new" className="btn btn-primary">+ New Note</Link>
      </div>

      {error && <div className="alert alert-error">{error}</div>}

      {notes.length === 0 ? (
        <div className="empty-state">
          <p>No notes yet.</p>
          <p style={{ marginTop: '8px' }}>
            <Link to="/notes/new">Create your first note</Link>
          </p>
        </div>
      ) : (
        notes.map((note) => (
          <div key={note.id} className="note-card">
            <div>
              <h3>{note.title}</h3>
              <div className="note-date">Last updated: {formatDate(note.updatedAt)}</div>
            </div>
            <div className="note-actions">
              <Link to={`/notes/${note.id}`} className="btn btn-secondary">View</Link>
              <Link to={`/notes/${note.id}/edit`} className="btn btn-primary">Edit</Link>
              <button
                className="btn btn-danger"
                onClick={() => handleDelete(note.id)}
              >
                Delete
              </button>
            </div>
          </div>
        ))
      )}
    </div>
  );
}

export default DashboardPage;

import { useState, useEffect } from 'react';
import { useParams, useNavigate } from 'react-router-dom';
import { createNote, updateNote, getNoteById } from '../services/api';

// Used for both Create (/notes/new) and Edit (/notes/:id/edit)
function NoteFormPage() {
  const { id } = useParams();
  const navigate = useNavigate();
  const isEditing = Boolean(id);

  const [title, setTitle] = useState('');
  const [content, setContent] = useState('');
  const [error, setError] = useState('');
  const [loading, setLoading] = useState(false);
  const [fetchLoading, setFetchLoading] = useState(isEditing);

  // If editing, load existing note
  useEffect(() => {
    if (!isEditing) return;

    getNoteById(id)
      .then((data) => {
        setTitle(data.note.title);
        setContent(data.note.content);
      })
      .catch((err) => setError(err.message))
      .finally(() => setFetchLoading(false));
  }, [id, isEditing]);

  async function handleSubmit(e) {
    e.preventDefault();
    setError('');
    setLoading(true);

    try {
      if (isEditing) {
        await updateNote(id, title, content);
        navigate(`/notes/${id}`);
      } else {
        const data = await createNote(title, content);
        navigate(`/notes/${data.note.id}`);
      }
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }

  if (fetchLoading) return <div className="loading">Loading...</div>;

  return (
    <div className="container">
      <div className="form-container" style={{ margin: '30px auto' }}>
        <h2>{isEditing ? 'Edit Note' : 'New Note'}</h2>

        {error && <div className="alert alert-error">{error}</div>}

        <form onSubmit={handleSubmit}>
          <div className="form-group">
            <label htmlFor="title">Title</label>
            <input
              id="title"
              type="text"
              value={title}
              onChange={(e) => setTitle(e.target.value)}
              required
              maxLength={200}
              placeholder="Note title"
            />
          </div>

          <div className="form-group">
            <label htmlFor="content">Content</label>
            <textarea
              id="content"
              value={content}
              onChange={(e) => setContent(e.target.value)}
              required
              maxLength={10000}
              placeholder="Write your note here..."
            />
          </div>

          <div style={{ display: 'flex', gap: '8px' }}>
            <button type="submit" className="btn btn-primary" disabled={loading}>
              {loading ? 'Saving...' : (isEditing ? 'Update Note' : 'Create Note')}
            </button>
            <button
              type="button"
              className="btn btn-secondary"
              onClick={() => navigate(isEditing ? `/notes/${id}` : '/')} 
            >
              Cancel
            </button>
          </div>
        </form>
      </div>
    </div>
  );
}

export default NoteFormPage;
